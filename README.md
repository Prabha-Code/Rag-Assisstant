# 🚀 AI Interview Mentor + Skill Gap Analyzer

An AI-powered Resume Analyzer that:

- Detects job role automatically
- Extracts required skills from job description
- Compares with resume skills
- Identifies skill gaps
- Generates AI-powered interview questions

---

## 🔥 Features

- Role Detection (ML Engineer, Data Scientist, Data Analyst, etc.)
- Skill Gap Analysis
- AI Interview Question Generation
- Terminal Version
- Web Deployment Version

---

## 🛠 Tech Stack

- Python
- OpenAI API
- pypdf
- Regex
- Streamlit (for web demo)

## ⚙ Installation (Local Setup)

### 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI_Interview_Mentor.git
cd AI_Interview_Mentor
```

### 2️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

### 3️⃣ Add OpenAI Key

Create `.env` file:

```
OPENAI_API_KEY=your_openai_api_key
```

---

## ▶ Run Terminal Version

```bash
python main.py
```

---

## 🌐 Run Web Version

```bash
streamlit run streamlit_app.py
```
